# Reflected Function Importer

We will import built-in and future user functions through a setup-time reflected function importer that converts explicitly supplied function providers into `FunctionDescriptor`s, instead of manually registering every method or using annotations. The importer will only inspect directly declared public methods, require explicit purity on every import, adapt `MethodHandle`s to the runtime's canonical value types, support explicit renames for Java methods whose language names differ, and reject duplicate function signatures before catalog registration. Provider construction remains explicit outside the importer so it stays a function-import tool rather than a dependency-injection container, and built-in completeness remains validated by independent expected signatures.
